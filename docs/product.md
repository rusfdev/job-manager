# Product

## What it is

A personal application that automatically collects job postings from
configurable sources and keeps them in one place: browse, dismiss, track
status.

## Who it is for

Job seekers, first of all the project author. Multiple users are supported
from the start, but there is no public sign-up: accounts are created manually,
users only authenticate.

## Key features

- Periodic automatic collection of job postings from configurable sources.
- Storage and management of postings: browse, dismiss, track status.
- Matching a posting against the resume: what is missing, key terms.
- Generating a resume and a cover letter tailored to a specific posting.
- Connecting an external AI agent to the server over MCP: the agent performs
  tasks on postings on demand without being part of the backend or depending
  on its API.
- A PWA user interface.
- Notifications about new postings via Telegram and/or web push in the PWA,
  user's choice.

## Goals

- Remove as much routine as possible from finding, tracking and managing
  job postings.
- Real personal use, not a learning or portfolio project.

## Non-goals

- Auto-applying: every decision on a posting is made by the user only.
- Public sign-up.
- A commercial product.
- A fixed set of sources: sources are configurable content, not part of the
  product.
